# 🥖 Boulangerie des Merveilles – Feuille de Temps (PWA)

## Déploiement GitHub Pages (10 minutes)

1) Créer un dépôt GitHub (ex : `bdm-feuille-temps`)
2) Uploader ces fichiers à la racine :
- `index.html`
- `manifest.json`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`

3) Activer Pages :
Settings → Pages → Deploy from a branch → Branch: main → /(root) → Save

4) URL :
https://VOTRE_COMPTE.github.io/bdm-feuille-temps/

## Installation mobile
- iPhone: Safari → Partager → Ajouter à l’écran d’accueil
- Android: Chrome → Menu ⋮ → Ajouter à l’écran d’accueil
